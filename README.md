## 🔧 Technical Support & Bug Reports

If you are experiencing any asset alignment bugs, font rendering issues, or general stability problems with our Nixie Clocks, Calendars, or VU Meters, please let us know:

* **File a Ticket:** Click on the **[Issues](../../issues)** tab at the top of this page.
* **Submit Details:** Provide your Stream Deck/iCUE software version and a quick description of the issue.

*Please note: Everything posted in public GitHub issues is visible to the web. Never share personal email addresses or license keys here.*
